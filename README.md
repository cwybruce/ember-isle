**Ember Isle** is a complete open-world crime game set on a tropical volcano island: black-sand beaches, lava flows, jungle dirt roads, and a volcano that glows at night. Explore on foot, steal cars (off-roader, pickup, sedan) and boats, outrun the police across a 5-star wanted system, take on a 4-mission story chain, fight with pistol / SMG / shotgun, and watch the island from a live minimap. Pure static files — no build step, no network requests, keyboard + mouse.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` directly from any static file server.
